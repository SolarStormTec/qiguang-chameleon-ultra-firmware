# Code of Conduct

We expect project participants to communicate respectfully, discuss technical decisions in good faith, and keep reviews focused on the work rather than the person. Harassment, discriminatory language, threats, publication of private information, and deliberate disruption are not acceptable.

Maintainers may edit or remove inappropriate contributions and may temporarily or permanently restrict participation when necessary. Report conduct concerns privately through a repository maintainer's GitHub profile contact method. Do not include sensitive personal information in a public issue.
